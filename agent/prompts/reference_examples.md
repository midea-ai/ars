# Reference Examples

The attached reference examples come from separate cases. They are not
evidence that any action or state transition occurred in the trajectory being
evaluated.

Use them to compare task-relevant entity states and relations. Ignore
incidental differences such as robot pose, motion path, timing, lighting,
camera artifacts, and background appearance.

When a reference description provides a recommended progress value, apply it
only when the evaluated trajectory visibly satisfies the corresponding
task-relevant state. Similar robot motion or overall visual appearance is not
sufficient.

When the evaluated state lies between two applicable reference states,
interpolate conservatively between their recommended values.
